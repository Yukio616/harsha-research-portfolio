HARSA VARTANAN — RESEARCH PORTFOLIO

Files:
- index.html
- style.css
- script.js
- assets/  (selected visuals extracted from the IIT Indore internship report)

To customize:
1. Open index.html and replace the LinkedIn URL and email.
2. Add your resume as assets/resume.pdf and change the Resume link.
3. Add your own profile/lab/project photos to assets/ if desired.
4. Open index.html in a browser to preview.
5. Upload the folder to a static host such as GitHub Pages, Netlify or Vercel.

The IIT Indore section is based on the uploaded internship report. XGBoost is included because you explicitly asked for it as part of your internship work; no performance/result number is claimed.
